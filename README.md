## Featured Full-Stack-Ready Project

### [Loader — Secure File Management System](https://github.com/robin1117/Express-File-Sharing-Server-System-)

A cloud file-management backend built for browser clients. It supports registration, sign-in, folders, file uploads, file browsing, preview/download access, and session management.

```text
Frontend / Browser
  │  JSON requests, CORS, signed session cookies, upload-progress headers
  ▼
Express REST API
  ├── Authentication & authorisation ──► Redis session store
  ├── Users, folders & file metadata ─► MongoDB / Mongoose
  ├── Multipart file upload & access ─► AWS S3
  └── OTP and reset emails ───────────► Resend
```

| User-facing capability | Implementation |
| --- | --- |
| Sign up and login | Zod validation, bcrypt password hashing, signed HTTP-only cookie sessions |
| Social login | Google and GitHub OAuth code exchange |
| File browser | Folder/file listing APIs with breadcrumbs, rename, and recursive deletion |
| Reliable uploads | AWS S3 multipart upload, chunk offsets, resume checks, and cancellation cleanup |
| Private file access | Short-lived S3 pre-signed URLs for preview or download |
| Account recovery | Email OTP verification and one-time password reset tokens |
| Session controls | Redis-backed expiry, logout from one or all devices, and role-aware user actions |
